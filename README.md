Hushline is a simple, account-free online chat app for private conversations and random group chats. Private chats connect two people using a secret code, while random group chats match up to five people without requiring a code. The app supports real-time messaging, mobile-friendly design, invite links, and no registration or login.
Hushline includes real-time messaging, room status updates, invite sharing, connection handling, group capacity limits, and a responsive interface that works on desktop computers, tablets, and mobile phones. The project uses WebRTC for peer-to-peer communication and a Node.js WebSocket server for random group matchmaking.
The goal of Hushline is to provide a fast, simple, and accessible way for people to start conversations online without creating an account.
